App architecture and live price path

What the code on main does. Live prices are fetched in the browser; the backend stores users, watchlists, and trades.

How a price update reaches the UI

  1. A page or panel mounts useStockQuote (stock detail) or useMultipleQuotes (dashboard, sidebar, watchlist panels).
  2. Every 5 seconds the hook calls stockApi.getQuote. It returns a cached copy under 5 seconds old. Otherwise it calls the external market-data API from the browser when a browser key is set, or generates a deterministic fallback quote in the browser.
  3. The hook stores the quote in React state, and the components re-render with the new price.
  4. The same quote feeds the stock detail price alert check (every 30 seconds, alerts in localStorage) and the trade form, which locks the price and posts it to /api/v1/portfolio/buy or sell. The backend saves the trade through Prisma.
